# Saberforge — локальный сайт конструктора светового меча

Готовый статический сайт: **HTML + CSS + JS**, без сервера, без баз данных, без внешних API,
без CDN и без загрузки шрифтов из интернета. Всё, что нужно, лежит в этой папке,
поэтому сайт полностью работает **офлайн** — хоть с интернетом, хоть без.

Сайт ничего и никуда не отправляет: фото, которое вы накладываете, обрабатывается
только в браузере на вашем устройстве.

---

## 1. Как открыть прямо сейчас (без установки чего-либо)

* Двойной клик по **`index.html`** — откроется в браузере (Chrome, Edge, Firefox, Safari).
* Или откройте **`saberforge-standalone.html`** — это тот же сайт, но вообще одним файлом
  (CSS и JS вшиты внутрь). Удобно переслать другу одним файлом.

Всё работает и без интернета: отключите Wi-Fi и обновите страницу — сайт останется прежним.

## 2. Как выложить в интернет бесплатно

Сайт статический, поэтому бесплатные хостинги подходят идеально — ни одна функция
не требует платного сервера или API. Самые простые варианты:

| Сервис | Что делать |
| --- | --- |
| **Netlify Drop** (netlify.com/drop) | перетащить папку с сайтом в окно браузера → получить ссылку. Без регистрации для черновика. |
| **Cloudflare Pages** | Create project → Direct upload → загрузить папку. Бесплатный тариф, HTTPS. |
| **GitHub Pages** | залить файлы в репозиторий → Settings → Pages → Branch: `main` / root. |
| **Vercel** | New Project → drag & drop папки (статический сайт, без сборки). |

Важно: на хостинг загружается **содержимое** папки — так, чтобы `index.html`
оказался в корне сайта.

## 3. Необязательно: локальный сервер

Обычно не нужен. Но если браузер капризничает с `file://` (например, Safari),
в папке есть мини-сервер на Python:

```bash
python3 start-server.py       # затем открыть http://localhost:8000
# или встроенный сервер Python:
python3 -m http.server 8000
```

## Управление

**Режим «3D-меч»:** тяните меч мышью — вращение, колесо мыши — масштаб,
стрелки `←/→` — поворот на 5°, `+`/`−` — масштаб, `Space` — включить/выключить клинок.
Слева — путь (джедай/ситх/свой), цвет кристалла и параметры клинка, справа — рукоять.

**Режим «Наложение»** (кнопка над сценой или пункт меню):

1. «Выбрать фото» / «Пример» / перетащить файл в окно / вставить из буфера `Ctrl + V`.
2. Тащите меч — двигаете; кружок на клинке — поворот (с `Shift` шаг 15°);
   нижний кружок, колесо мыши или `−/+` — размер; на телефоне — пинч двумя пальцами.
3. «Отразить» — перевернуть другим концом, «Сброс» — вернуть на место.
4. Кнопка в шапке «Сохранить фото» скачивает готовый PNG в исходном разрешении картинки.

Всё остальное (цвет, рукоять, длина клинка, свечение) берётся из конструктора слева и справа
и сразу применяется к мечу на фото.

## Что внутри

```
index.html                  главная страница
saberforge-standalone.html  то же самое одним файлом (всё вшито)
app.js                      логика конструктора и наложения на фото
styles.css                  оформление
assets/demo-photo.js        демо-фото (вшито как data URI — работает офлайн)
assets/demo-portrait.jpg    то же фото отдельным файлом (резерв)
start-server.py             мини-локальный сервер для http://localhost
README.md                   этот файл
```

## Про «функцию определения интернета»

Внутри нет ни одного сетевого запроса, поэтому проверять наличие интернета
незачем: сайт не зависит от сети вообще. Иконки, меч, рукояти, фон и звёзды
рисуются кодом (SVG + Canvas), шрифты — системные.

## Сохранение настроек

Кнопка «В коллекцию» (или `Ctrl/⌘ + S`) кладёт конфигурацию меча в `localStorage`
браузера — это тоже локально, ничего не отправляется. Коллекция живёт в том браузере,
в котором вы её создали.
